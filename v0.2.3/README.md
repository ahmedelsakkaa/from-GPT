# SAKA WATER MODEL BUILDER v0.2.3

1. Download this repository as ZIP from GitHub and extract it.
2. Open the `v0.2.3` folder.
3. Run `REBUILD_v0.2.3.cmd`.
4. It will create `SAKA_WATER_MODEL_BUILDER_v0.2.3_UI_RUNTIME_DIAGNOSTICS.zip`.
5. Extract that ZIP and run its `BUILD.bat`.
6. Test `G04-R88 + G04-R65 + G04-R99`, then test `G04-R58`.
7. If any route fails, use `COPY FULL REPORT` and send the complete report.

Use the files under `package/`. The older `transfer/` folder was an incomplete transfer attempt and is not needed.
